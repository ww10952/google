# Tab Manager Pro

强大的Chrome标签页管理工具，帮助你更高效地管理浏览器标签页。

## 功能特性

### 主界面
- **双栏布局**: 左侧分组管理 + 右侧标签页列表
- **分组管理**: 
  - 创建新分组（支持8种颜色选择）
  - 编辑分组名称和颜色
  - 折叠/展开分组
  - 取消单个或全部分组
  - 点击分组快速筛选标签页
- **标签页管理**: 
  - 显示所有打开的标签页
  - 支持按标题和URL搜索
  - 多选标签页
  - 快速激活和关闭标签页
  - 显示分组标签和图标
- **标签页集合**: 保存和加载标签页配置
- **关闭重复标签**: 一键检测并关闭重复的标签页
- **标签页使用统计**: 查看标签页使用频率和域名统计

### 新标签页
- **美观的界面**: 渐变背景，现代化设计
- **时钟和日期**: 实时显示当前时间和日期
- **智能搜索**: 支持网址直接访问和Bing搜索
- **右侧标签页侧边栏**: 
  - 吸附在浏览器右侧
  - 可收起/展开
  - 收起时只显示网站图标
  - 展开时显示图标、标题、域名
  - 快速激活和关闭标签页
- **分组概览**: 查看所有标签页分组
- **最近关闭**: 恢复最近关闭的标签页
- **快捷操作**: 一键打开管理器、关闭所有标签页等
- **底部状态栏**: 显示标签页和分组统计

### 设置选项
- **使用自定义新标签页**: 开启/关闭新标签页功能
- **自动激活新标签页**: 创建或切换标签页时自动激活
- **显示标签页数量**: 在工具栏图标上显示标签页数量
- **最大标签页数限制**: 超过此数量时显示警告
- **自动分组**: 根据域名自动创建分组
- **默认分组颜色**: 新分组的默认颜色

## 安装方法

请查看 [INSTALL.md](INSTALL.md) 文件获取详细的安装说明。

**快速安装：**
1. 打开 Chrome/Edge 浏览器
2. 访问 `chrome://extensions/` 或 `edge://extensions/`
3. 开启右上角的"开发者模式"
4. 将此文件夹直接拖拽到浏览器窗口中
5. 点击"添加扩展程序"确认安装

## 使用说明

### 界面布局

插件采用双栏布局：
- **左侧**: 分组管理面板
- **右侧**: 标签页列表

### 分组管理

#### 创建新分组
1. 点击左侧面板顶部的 `➕` 按钮
2. 输入分组名称
3. 选择分组颜色（8种颜色可选）
4. 点击"保存"

#### 编辑分组
1. 点击分组项右侧的 `✏️` 按钮
2. 修改名称或颜色
3. 点击"保存"

#### 折叠/展开分组
点击分组项右侧的 `📁/📂` 按钮切换折叠状态

#### 取消分组
- 单个分组: 点击 `❌` 按钮取消该分组
- 全部分组: 点击"取消全部分组"按钮

#### 筛选标签页
- 点击分组卡片显示该分组下的标签页
- 点击"全部标签"显示所有标签页
- 点击"未分组"显示未分组的标签页

### 标签页管理

- **搜索标签页**: 在右侧搜索框中输入关键词，实时过滤标签页
- **多选标签页**: 勾选复选框选择多个标签页
- **切换标签页**: 点击标签页项或"激活"按钮
- **关闭标签页**: 点击标签页项的"关闭"按钮

### 高级功能

#### 关闭重复标签
点击底部的"❌ 关闭重复"按钮，自动检测并关闭URL相同的重复标签页。

#### 保存标签页集合
1. 点击"💾 保存集合"按钮
2. 输入集合名称
3. 点击"保存"

#### 加载标签页集合
1. 点击"📂 加载集合"按钮
2. 从列表中选择要加载的集合
3. 点击"打开"按钮

#### 查看统计
点击"📊 统计"按钮查看：
- 总标签页数
- 分组数量
- 未分组标签页数
- 最常访问的域名

### 新标签页使用

#### 开启新标签页
1. 点击工具栏图标打开管理器
2. 点击底部"⚙️ 设置"按钮
3. 勾选"使用自定义新标签页"
4. 保存设置并重新加载扩展

#### 新标签页功能

**时间显示**
- 大型时钟显示当前时间
- 显示完整的日期（星期、年月日）

**智能搜索**
- 输入网址直接访问（支持自动添加https://）
- 输入关键词进行Bing搜索
- 按回车键或点击🔍按钮

**右侧标签页侧边栏**
- 显示所有打开的标签页
- 点击`◀/▶`按钮收起/展开侧边栏
- **收起状态**: 只显示网站图标
- **展开状态**: 显示图标、标题、域名
- 鼠标悬停显示操作按钮
- 点击标签页快速激活
- 快速关闭标签页

**分组概览**
- 查看所有标签页分组
- 显示分组颜色和标签数
- 点击展开/激活分组

**最近关闭**
- 显示最近关闭的5个标签页
- 一键恢复已关闭的标签页

**底部状态栏**
- 显示标签页和分组统计
- 快速打开设置页面

## 快捷键

- 显示标签页数量徽章
- 最大标签页数限制
- 自动分组相似标签页
- 默认分组颜色

## 数据管理

插件支持：
- 导出数据备份
- 导入数据恢复
- 清除所有数据
